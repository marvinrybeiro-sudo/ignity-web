# Orientações do projeto web

Este projeto usa o Framework Agêntico Web. Para iniciar ou retomar o fluxo completo, carregar `web-orchestrator` em `.claude/skills/web-orchestrator/SKILL.md`, disponível também como `/web-orchestrator` no Claude Code. Para uma alteração pontual, ler o estado e carregar apenas os módulos pertinentes.

Contexto: `project/BRIEF.md`. Continuidade: `project/STATE.md`. Decisões: `project/DECISIONS.md`. Referências e QA: demais arquivos em `project/`. Guia: `.ignity/framework/FRAMEWORK.md` (em instalações v1, `project/framework/FRAMEWORK.md`).

Preservar conteúdo nativo e editável no Elementor, reutilizar componentes e conferir desktop/mobile. Descobrir o MCP e o schema reais, ler a revisão atual antes de editar e verificar persistência. Não transportar IDs, acessos ou decisões de outra marca. Priorizar o pedido atual e as autorizações existentes; o framework não concede permissões adicionais.

Não abrir agentes paralelos automaticamente. Registrar evidência e próximo passo ao encerrar. Não salvar segredos ou URLs assinadas nos registros. Se estas orientações forem adicionadas a um projeto existente, mesclar com suas instruções sem apagar regras anteriores.

Ao iniciar a sessão, sugerir o próximo passo a partir de `project/STATE.md`.
