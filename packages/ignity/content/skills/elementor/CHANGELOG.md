# Changelog da skill elementor

Skill de autoria do usuário, versionada neste arquivo.

## 1.1.0 — 2026-11-08

Custom Fonts permanece como padrão. Google Fonts como origem passa a ser aceita via arquivos self-hosted, com licença web, sem CDN por padrão. Família, pesos e estilos vêm do BRIEF ou Figma. Mudança limitada ao bloco original das linhas 53–54 (SYS-04/EL-07, REQ-07, REQ-10).

## 1.0.0 — 2026-11-08

Versão original do usuário no kit v1. Texto original para rollback:

```text
- Use somente fontes cadastradas em Custom Fonts do Elementor; não use Google Fonts. Confirme a disponibilidade por um recurso que liste fontes personalizadas ou pelo painel. Estilos globais, sozinhos, não comprovam esse cadastro.
- Se a fonte da referência não estiver cadastrada, pergunte qual fonte disponível usar ou solicite o arquivo/licença apropriados. Não substitua silenciosamente.
```
