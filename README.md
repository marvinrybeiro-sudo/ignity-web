# Ignity Web

Framework para projetos WordPress e Elementor com Claude Code e Codex.

```bash
npx ignity-web init
```

Requer Node.js 22 ou superior e Elementor Pro Advanced ou superior. Versão alpha.

O código do pacote está em `packages/ignity/`. O kit v1 em `framework-agentico-web/` é mantido como fixture de compatibilidade para os testes.

```bash
npm --prefix packages/ignity test
npm --prefix packages/ignity run build
```

Veja [documentação do pacote](packages/ignity/README.md). Licença MIT.
